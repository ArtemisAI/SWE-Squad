SWE-Squad

An autonomous AI engineering team that monitors your systems, triages issues, investigates root causes, writes fixes, and opens PRs — all while you sleep.

Get Started

Features

Everything you need for autonomous software maintenance, from detection to deployment.

🔍

Multi-Agent Triage

Monitor agent scans logs across local and remote nodes, deduplicates errors by fingerprint, and classifies severity automatically.

🧠

Semantic Memory

pgvector-backed memory pipeline with bge-m3 embeddings. Past investigations are recalled and injected into new ones, improving over time.

🔧

Auto-Fix PRs

Developer agent writes fixes in isolated worktrees, runs tests, checks complexity gates, and opens pull requests — zero human intervention.

🌐

Cross-Repo Support

Monitor multiple repositories from a single instance. Tickets are scoped per-repo with automatic SSH-based log collection from remote workers.

📊

Real-Time Dashboard

Built-in HTTP dashboard with live ticket counts, gate verdicts, cycle history, and cost tracking. Also available as Telegram alerts.

🧩

Plugin Architecture

12 provider interfaces: swap coding engines, notification channels, issue trackers, vector stores, and more without changing core code.

Getting Started

Three steps from zero to autonomous engineering.

1

Install

git clone https://github.com/ArtemisAI/SWE-Squad.git cd SWE-Squad pip install -e ".[embeddings]"
2

Configure

cp .env.example .env # Set your tokens: # GH_TOKEN, TELEGRAM_BOT_TOKEN, # SUPABASE_URL, SUPABASE_ANON_KEY vi config/swe_team.yaml
3

Run

# Single cycle python scripts/ops/swe_team_runner.py # Daemon mode (recommended) python scripts/ops/swe_team_runner.py --daemon # Check status python scripts/ops/swe_cli.py status
